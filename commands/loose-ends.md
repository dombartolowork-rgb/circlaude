Use the `circle-loose-ends` skill.

Look back over the last 30 days unless a different period is given below. Start
with the threads where the user's own message is still the last word and it
asked for something, and for each one work out what it is blocking. Then the
actions they took on in calls, drafts older than three days, and inbound mail
that sank without a reply.

Report one list, oldest first in each group, one line per item. Do not draft
anything yet. Ask which to chase first, then work through them one at a time,
drafting and showing each before sending.
